Comment travailler

Quatre exercices, dans l'ordre. Ne passez pas au suivant tant que le précédent ne fonctionne pas.

Le socle, c'est ce que tout le monde doit finir. Les exercices 0, 1 et 2 portent tout ce qui compte pour la séance 2. Si vous les avez terminés et qu'il vous reste du temps, passez à l'exercice 3, puis au bonus.

Si vous n'avez pas fini le socle en séance, terminez-le chez vous avant la séance 2 : la note de participation regarde que le travail est fait, pas qu'il a été fait vite. Et si vous bloquez, écrivez dans l'issue du dépôt d'exercices — c'est fait pour ça.

Si vous travaillez sur Google Colab ou sur téléphone, chaque exercice a une variante indiquée. Vous ferez la même chose, sans les commandes uv.

Rappel de la règle du cours : on exécute avec uv run fichier.py, jamais avec python fichier.py.

Exercice 1 — Traduire, puis réécrire

10 minutes. Socle. Deux programmes, deux étapes chacun. Les deux étapes comptent.

Chaque programme est donné en C++ et en PHP. Les deux versions font exactement la même chose : lisez celle du langage que vous connaissez le mieux, ignorez l'autre.

Pour chacun des deux programmes :

  • Étape A — traduisez ligne à ligne, sans réfléchir au style. Le but est que ça marche.
  • Étape B — réécrivez votre traduction pour qu'elle ressemble à du Python. Vous avez le droit de faire disparaître des lignes.

Créez exercice1.py dans votre projet.

Programme A — le maximum d'une série

En C++

C++
123456789
int temperatures[] = {31, 29, 33, 35, 30, 28, 32};
int taille = 7;
int max = temperatures[0];
for (int i = 1; i < taille; i++) {
    if (temperatures[i] > max) {
        max = temperatures[i];
    }
}
cout << "Maximum : " << max << endl;

En PHP

PHP
12345678
$temperatures = [31, 29, 33, 35, 30, 28, 32];
$max = $temperatures[0];
for ($i = 1; $i < count($temperatures); $i++) {
    if ($temperatures[$i] > $max) {
        $max = $temperatures[$i];
    }
}
echo "Maximum : " . $max . "\n";

Les deux affichent Maximum : 35.

Si le temps manque, faites le programme A en entier plutôt que les deux à moitié.

Programme B — une liste numérotée

En C++

C++
12345
string villes[] = {"Port-au-Prince", "Cap-Haïtien", "Les Cayes", "Jacmel"};
int taille = 4;
for (int i = 0; i < taille; i++) {

En PHP

PHP
1234
$villes = ["Port-au-Prince", "Cap-Haïtien", "Les Cayes", "Jacmel"];
for ($i = 0; $i < count($villes); $i++) {
    echo ($i + 1) . ". " . $villes[$i] . "\n";
}

L'affichage attendu pour le programme B :

3. Les Cayes

Indice pour l'étape B. Un seul des trois outils vus en cours — range, enumerate, zip — vous servira. Et l'un des deux programmes n'a plus besoin d'aucune boucle.

Variante Colab / téléphone. Une cellule par programme, une sous-cellule par étape.

Exercice 2 — Chasse aux réflexes

7 minutes. Socle — c'est l'exercice le plus important de la séance.

Le programme ci-dessous fonctionne et donne le bon résultat. Il est pourtant écrit comme du C++ ou du PHP.

Python
1234567891011121314
notesEtudiants = [12, 17, 9, 14, 18, 7, 15]
notesReussite = []
i = 0
while i < len(notesEtudiants):
    if notesEtudiants[i] >= 10:
        notesReussite.append(notesEtudiants[i])
    i = i + 1

if len(notesReussite) > 0:
    somme = 0
    for j in range(len(notesReussite)):
        somme = somme + notesReussite[j]
    moyenne = somme / len(notesReussite)
    print("Moyenne des reçus : " + str(moyenne))

Ce qu'on vous demande, dans exercice2.py :

  1. Listez en commentaire, en tête du fichier, six choses qui trahissent une habitude venue du C++ ou du PHP.

  2. Réécrivez le programme. Il doit produire le même résultat, en moins de lignes.

  3. Affichez la moyenne avec une seule décimale.

  4. Une question pour finir, en commentaire à la fin du fichier : dans quel cas la ligne qui calcule la moyenne planterait-elle, et qu'est-ce qui l'en empêche ici ?

Attention. Aucune des six choses que vous allez repérer n'est une faute : le programme marche. Ce sont des marques d'écriture, et dans ce cours elles sont comptées comme des erreurs de style.

Exercice 3 — Un petit programme complet

8 minutes. Extension — à faire si le socle est terminé.

Écrivez bulletin.py. Le programme doit :

  1. Demander le nom de l'étudiant
  2. Demander trois notes, une par une
  3. Refuser de continuer si une note n'est pas comprise entre 0 et 20 — affichez Note invalide et arrêtez-vous là
  4. Calculer la moyenne
  5. Afficher une ligne de la forme exacte :
Code
1
Ana : moyenne 14.7 sur 20 — mention bien

Le barème des mentions :

Moyenne Mention
16 et plus très bien
de 14 à moins de 16 bien
de 10 à moins de 14 passable
moins de 10 insuffisant

Quatre contraintes de style, qui seront regardées :

  • La moyenne s'affiche avec une seule décimale
  • Utilisez une f-string, pas de concaténation avec +
  • Utilisez une comparaison enchaînée pour la validation des notes
  • snake_case, quatre espaces d'indentation

Variante Colab / téléphone. input fonctionne dans Colab, mais si la saisie vous ralentit, remplacez les quatre input par quatre variables écrites en tête de cellule. Le reste du programme est identique.
