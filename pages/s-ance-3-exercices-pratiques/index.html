Exercice 1 Cinq programmes cassés

12 minutes. Socle c'est l'exercice le plus important de la séance.

Vous ne devez rien réparer. Pour chacun des cinq programmes, exécutez-le et répondez à trois questions, dans diagnostics.md :
a) Quel est le type de l'erreur ? (le dernier mot avant les deux-points de la dernière ligne)
b) À quelle ligne de quel fichier l'exécution s'est-elle arrêtée ?
c) Quelle ligne faut-il corriger, et pourquoi ? (ce n'est pas toujours la même que la b)

Une réponse en trois lignes par programme suffit. C'est la question c) qui compte.

Créez les cinq fichiers dans votre projet, ou récupérez-les depuis le dépôt d'exercices.

Exercice 2 Trois fonctions qui s'appellent

10 minutes. Socle.

Dans exercice2.py, écrivez ces trois fonctions, dans cet ordre. Chacune doit avoir une docstring d'une ligne.

1. est_reussie(note, seuil=10) renvoie True si la note atteint le seuil, False sinon.

Python
123
est_reussie(12)              # True
est_reussie(9)               # False
est_reussie(9, seuil=8)      # True

2. notes_reussies(notes, seuil=10) renvoie la liste des notes qui atteignent le seuil. Elle doit appeler est_reussie.

Python
123
notes = [12, 17, 9, 14, 18, 7, 15]
notes_reussies(notes)               # [12, 17, 14, 18, 15]
notes_reussies(notes, seuil=15)     # [17, 18, 15]

3. resume_notes(notes) renvoie deux valeurs : le nombre de notes reçues et leur moyenne. Elle doit appeler notes_reussies.

Python
12
nombre, moyenne = resume_notes(notes)
print(f"{nombre} reçus, moyenne {moyenne:.1f}")
Code
1
5 reçus, moyenne 15.2

Ce 15.2 est celui de la séance 1 et de la séance 2. Si vous obtenez autre chose, l'erreur est dans vos fonctions, pas dans le calcul.

Trois contraintes :

  • notes_reussies doit appeler est_reussie ne recopiez pas la condition
  • Aucun print à l'intérieur des trois fonctions. Elles renvoient, elles n'affichent pas
  • Une docstring d'une ligne par fonction

Puis une question, en commentaire : que doit renvoyer resume_notes([3, 5, 8]), où personne n'est reçu ? Faites en sorte que votre programme ne plante pas, et dites en une phrase quelle erreur vous avez évitée.

Exercice 3 Votre bulletin de la séance 1

6 minutes. Extension à faire si le socle est terminé.

Reprenez le bulletin.py de l'exercice 3 de la séance 1. Dans exercice3.py, réécrivez-le avec deux fonctions :

  • mention(moyenne) renvoie "très bien", "bien", "passable" ou "insuffisant"
  • bulletin(nom, notes, avec_mention=True) renvoie la ligne complète, et appelle mention

Puis, sans input, à partir de ces deux listes :

Python
12
noms = ["Ana", "Jean", "Marie"]
notes = [[12, 17, 14], [9, 11, 8], [18, 16, 19]]

Affichez les trois bulletins, puis une quatrième ligne pour Luc, avec les notes [15, 15, 15] et sans mention.

L'affichage attendu :

Code
1234
Ana : moyenne 14.3 sur 20  mention bien
Jean : moyenne 9.3 sur 20  mention insuffisant
Marie : moyenne 17.7 sur 20  mention très bien
Luc : moyenne 15.0 sur 20

Trois contraintes de style :

  • Aucun for i in range(len(...)) les deux listes se parcourent en parallèle
  • mention utilise plusieurs return, pas une variable qu'on modifie
  • Une docstring par fonction
