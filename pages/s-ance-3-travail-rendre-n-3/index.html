Les cinq fonctions à écrire

Elles sont imposées : mêmes noms, mêmes paramètres, mêmes valeurs par défaut. C'est ce qui rend la correction possible, et c'est aussi ce qui vous évite de chercher un découpage.

1. calculer_montants(lignes)

Ajoute une clé montant à chaque ligne, valant quantite × prix_unitaire. Ne renvoie rien elle modifie la liste sur place.

2. grouper_par(lignes, cle, valeur="montant")

Renvoie un dictionnaire qui associe chaque valeur de cle à la somme du champ valeur.

Python
12
grouper_par(ventes, "departement")                      # somme des montants
grouper_par(ventes, "categorie", valeur="quantite")     # somme des quantités

C'est la fonction centrale du travail. Un seul corps de boucle, qui remplace les quatre blocs copiés-collés de la semaine dernière.

3. filtrer(lignes, cle, valeur)

Renvoie la liste des lignes dont le champ cle vaut exactement valeur. Une compréhension d'une ligne.

Python
1
filtrer(ventes, "departement", "Ouest")

4. resume(lignes)

Renvoie trois valeurs : le nombre de lignes, le montant total, le montant moyen.

Python
1
nombre, total, moyenne = resume(ventes)

Sur une liste vide, elle ne doit pas planter. À vous de décider ce qu'elle renvoie dans ce cas et de le dire dans NOTES.md.

5. afficher_tableau(titre, totaux, unite="HTG")

Affiche un titre puis le dictionnaire, trié par valeur décroissante, une ligne vide à la fin.

Les contraintes d'écriture

Ce qui est exigé
1 Les six fonctions ont exactement les noms et les paramètres imposés. C'est la contrainte qui rend la correction possible
2 Chaque fonction a une docstring d'une ligne. Elle est notée pour la première fois
3 Aucun print dans calculer_montants, grouper_par, filtrer ni resume. Elles calculent, elles n'affichent pas
4 Aucune variable globale n'est lue à l'intérieur d'une fonction. Tout entre par les paramètres. SEUIL n'apparaît qu'au dernier appel
5 Aucun for i in range(len(...)) −1 point par occurrence
6 filtrer est une compréhension sur une ligne
7 snake_case, quatre espaces, f-strings partout. Aucune variable nommée sum, max, list, dict, set
8 donnees.py est inchangé

La contrainte 4 est celle qui sépare les copies. Il est tentant d'écrire def grouper_par(cle): et d'utiliser ventes directement à l'intérieur, puisque la variable existe. Ça marche et la fonction devient inutilisable sur autre chose que ventes. Une fonction qui dépend de ce qu'il y a autour d'elle n'est pas une fonction, c'est un bloc de code avec un nom.
