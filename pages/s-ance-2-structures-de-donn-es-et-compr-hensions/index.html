1. Les listes, pour de vrai

La séance 1 a montré qu'une liste se parcourt. Elle se découpe aussi, et elle se copie mal.

Indexation et index négatifs

Python
12345
jours = ["lundi", "mardi", "mercredi", "jeudi", "vendredi", "samedi", "dimanche"]

jours[0]     # 'lundi'
jours[-1]    # 'dimanche'   le dernier, sans calculer la longueur
jours[-2]    # 'samedi'

L'index négatif n'existe ni en C++ ni en PHP. En C++ il lirait de la mémoire au hasard ; en PHP il chercherait une clé qui s'appelle -1. En Python, il compte depuis la fin. C'est un vrai confort : ma_liste[-1] est toujours le dernier élément.

Le découpage

Python
12345
jours[:3]      # ['lundi', 'mardi', 'mercredi']       du début à 3 exclu
jours[5:]      # ['samedi', 'dimanche']               de 5 à la fin
jours[1:4]     # ['mardi', 'mercredi', 'jeudi']
jours[::2]     # un élément sur deux
jours[::-1]    # la liste à l'envers

La borne de droite est exclue. jours[1:4] donne trois éléments, pas quatre. C'est déroutant au début, et c'est ce qui fait que jours[:3] et jours[3:] se recollent exactement : pas de recouvrement, pas de trou.

Le découpage ne plante jamais : jours[:99] renvoie toute la liste sans erreur.

Les méthodes qui servent

Python
12345678
courses = ["riz", "mais"]

courses.append("haricot")      # ajoute à la fin
courses.insert(0, "sel")       # insère à une position
courses.remove("mais")         # retire la première occurrence
dernier = courses.pop()        # retire et renvoie le dernier
courses.sort()                 # trie SUR PLACE
len(courses)                   # la longueur

Un piège qui tombera dans les exercices :

Python
12
resultat = courses.sort()
print(resultat)     # None

sort() trie la liste et ne renvoie rien. Si vous voulez une nouvelle liste triée sans toucher à l'originale, utilisez sorted(courses).

Cette paire revient partout en Python : la méthode modifie l'objet, la fonction renvoie un nouvel objet. liste.sort() contre sorted(liste), liste.reverse() contre reversed(liste).

Copier une liste

Souvenez-vous de la séance 1 :

Python
1234
a = [1, 2, 3]
b = a            # PAS une copie : deux étiquettes sur le même objet
b.append(4)
print(a)         # [1, 2, 3, 4]

Pour obtenir une vraie copie :

Python
123
c = a.copy()     # ou a[:]
c.append(5)
print(a)         # inchangée

Si vous venez du PHP, attention : là-bas, $b = $a sur un tableau fait une vraie copie. Python fait exactement l'inverse. C'est le piège numéro un des développeurs PHP qui passent à Python, et il coûte des heures de débogage.

2. Tuples et ensembles

Deux structures, deux usages précis.

Le tuple : une liste qu'on ne modifie pas

Python
123
point = (3, 7)
point[0]          # 3
point[0] = 5      # erreur : un tuple ne se modifie pas

Ce qui le rend utile, c'est le déballage :

Python
12
x, y = point
nom, note = "Ana", 17

Et vous l'utilisez déjà sans le savoir — le zip de la séance dernière déballait un tuple à chaque tour :

Python
12
for nom, note in zip(noms, notes):
    ...

Quand préférer un tuple à une liste : quand la donnée ne doit pas changer, et quand le nombre d'éléments fait partie du sens — des coordonnées, une paire, un retour à deux valeurs.

L'ensemble : l'unicité et l'appartenance

Python
1234
produits = {"riz", "mais", "riz", "haricot"}
print(produits)             # {'riz', 'mais', 'haricot'} — les doublons ont disparu

"riz" in produits           # True, et c'est immédiat même sur un million d'éléments

Deux usages, et c'est tout ce dont vous aurez besoin :

Python
12
sans_doublons = set(ma_liste)
produits = sorted(set(ma_liste))      # dédoublonné et trié

Un ensemble n'a pas d'ordre. Si vous voulez un résultat ordonné, passez par sorted().

3. Les dictionnaires

C'est la structure la plus utilisée de Python, et celle sur laquelle repose tout le reste du cours.

Python
12345
etudiant = {"nom": "Ana", "note": 17, "departement": "Ouest"}

etudiant["nom"]                    # 'Ana'
etudiant["note"] = 18              # on modifie
etudiant["present"] = True         # on ajoute une clé

Si vous venez du PHP, c'est votre tableau associatif, avec la même syntaxe ou presque. Vous êtes en terrain connu. Si vous venez du C++, c'est une std::map, en beaucoup plus souple : les valeurs peuvent être de n'importe quel type, y compris d'autres dictionnaires.

La clé absente

Python
12345
etudiant["adresse"]                    # KeyError : la clé n'existe pas

etudiant.get("adresse")                # None, pas d'erreur
etudiant.get("adresse", "inconnue")    # 'inconnue', valeur par défaut
"adresse" in etudiant                  # False

get avec une valeur par défaut est le geste le plus utile de la séance. Il sert à compter :

Python
1234567
mots = ["riz", "mais", "riz", "haricot", "riz"]

compte = {}
for mot in mots:
    compte[mot] = compte.get(mot, 0) + 1

print(compte)      # {'riz': 3, 'mais': 1, 'haricot': 1}

Relisez cette boucle jusqu'à ce qu'elle soit évidente. C'est le motif le plus réutilisable du cours : à la première rencontre du mot, get renvoie 0, on écrit 1 ; ensuite on incrémente.

Parcourir un dictionnaire

Python
12345678
for cle in etudiant:                       # les clés
    print(cle)

for valeur in etudiant.values():           # les valeurs
    print(valeur)

for cle, valeur in etudiant.items():       # les deux — c'est celui qu'on utilise
    print(cle, ":", valeur)

.items() renvoie des tuples, que l'on déballe — exactement comme zip.

Une liste de dictionnaires est un tableau de données

C'est le point d'arrivée de la séance.

Python
12345
ventes = [
    {"produit": "riz",     "departement": "Ouest",      "quantite": 120},
    {"produit": "mais",    "departement": "Artibonite", "quantite": 340},
    {"produit": "haricot", "departement": "Ouest",      "quantite": 85},
]

Regardez la forme : une ligne par enregistrement, une clé par colonne. C'est exactement ce qu'est un fichier CSV, et exactement ce que sera un tableau pandas à la séance 5.

Trois opérations, qui reviendront toute l'année :

Python
123456789101112131415
# FILTRER
ouest = []
for v in ventes:
    if v["departement"] == "Ouest":
        ouest.append(v)

# CALCULER UNE COLONNE
for v in ventes:
    v["total"] = v["quantite"] * 100

# REGROUPER
par_departement = {}
for v in ventes:
    dep = v["departement"]
    par_departement[dep] = par_departement.get(dep, 0) + v["quantite"]

Ces trois boucles s'appellent filtrer, calculer, regrouper. À la séance 5, pandas les fera en une ligne chacune — et vous comprendrez ce qu'il fait parce que vous les aurez écrites à la main.

4. Les compréhensions

La forme

Python
12345678
# ce que vous avez écrit la semaine dernière
resultat = []
for note in notes:
    if note >= 10:
        resultat.append(note)

# la même chose
resultat = [note for note in notes if note >= 10]

Lisez-la à voix haute dans l'ordre où elle s'écrit :

« Une liste — de note — pour chaque note dans notes — si note >= 10 »

En trois temps :

Python
123
[note for note in notes]                  # tout copier
[note * 2 for note in notes]              # transformer
[note for note in notes if note >= 10]    # filtrer

L'ordre d'écriture est contre-intuitif : la transformation vient en premier, la source ensuite, la condition en dernier. Personne ne trouve ça naturel au début.

Trois exemples

Python
12345
noms = ["ana", "jean", "marie"]

majuscules = [nom.upper() for nom in noms]         # ['ANA', 'JEAN', 'MARIE']
longs = [nom for nom in noms if len(nom) > 3]      # ['jean', 'marie']
longueurs = [len(nom) for nom in noms]             # [3, 4, 5]

La compréhension de dictionnaire

Python
1234
prix = {"riz": 285, "mais": 95, "haricot": 410}

en_dollars = {produit: valeur / 130 for produit, valeur in prix.items()}
chers = {produit: valeur for produit, valeur in prix.items() if valeur > 200}

Même logique, avec cle: valeur devant le for.

La règle du cours

Une compréhension tient sur une ligne et ne contient pas d'autre compréhension. Dès qu'il vous faut deux conditions imbriquées ou une boucle dans une boucle, revenez à un for classique : c'est plus lisible, et ce sera mieux noté.

Et si les compréhensions ne passent pas aujourd'hui, ce n'est pas grave. Une boucle for correcte vaut tous les points au travail à rendre. La compréhension est un confort d'écriture, pas un critère d'évaluation. Écrivez la boucle juste plutôt que la compréhension fausse.

5. Les outils qui reviendront tout le semestre

Python
1234567891011
# trier selon un critère
ventes_triees = sorted(ventes, key=lambda v: v["quantite"], reverse=True)

# le maximum selon un critère
meilleure = max(ventes, key=lambda v: v["quantite"])

# sum sur une compréhension
total = sum(v["quantite"] for v in ventes)

# dédoublonner et trier
produits = sorted({v["produit"] for v in ventes})

Sur lambda : c'est une petite fonction sans nom, écrite sur place. Vous en avez besoin aujourd'hui pour trier ; on la verra vraiment à la séance 3. Pour l'instant, retenez la forme : key=lambda v: v["quelque_chose"].

À retenir de cette séance

  1. Le découpage [début:fin] exclut la borne de droite, et [-1] est le dernier élément
  2. liste.sort() ne renvoie rien ; sorted(liste) renvoie une nouvelle liste
  3. b = a ne copie pas une liste. b = a.copy() si.
  4. dictionnaire.get(cle, defaut) évite le KeyError — et sert à compter
  5. Une liste de dictionnaires est un tableau de données : une ligne par enregistrement, une clé par colonne

Aide-mémoire : erreurs fréquentes

Message d'erreur Cause probable
KeyError: 'xxx' Clé absente du dictionnaire. Utilisez .get() ou testez avec in
TypeError: 'NoneType' object is not iterable Vous avez écrit liste = liste.sort(). sort() ne renvoie rien
IndexError: list index out of range Index au-delà de la fin. Le découpage, lui, ne lève jamais cette erreur
TypeError: unhashable type: 'list' Une liste utilisée comme clé de dictionnaire. Les clés doivent être immuables
SyntaxError dans une compréhension Le if écrit avant le for, ou des crochets oubliés
Une liste change sans qu'on y touche b = a au lieu de b = a.copy()

collections.Counter

Python
123
from collections import Counter
compte = Counter(mots)
compte.most_common(3)

Fait en une ligne le comptage du module 3, et donne le classement en prime. Pourquoi pas au cours : vous devez d'abord savoir écrire la boucle avec get, sinon Counter reste une boîte noire. Servez-vous-en une fois que la boucle vous est évidente.

defaultdict

from collections import defaultdict — un dictionnaire qui crée la valeur par défaut tout seul, ce qui évite le get(cle, 0). Pourquoi pas au cours : get suffit, et se lit sans documentation.

Les opérations d'ensemble

Python
123
a | b     # union
a & b     # intersection
a - b     # différence

Élégant, et utile le jour où vous comparerez deux listes d'identifiants. Pourquoi pas au cours : ça ne sert nulle part dans les quatre séances qui restent.

dict ordonné, et pourquoi on n'en parle pas

Depuis Python 3.7, un dictionnaire conserve l'ordre d'insertion. Ça n'a l'air de rien et ça a changé beaucoup de code. Où chercher : « What's New in Python 3.7 ».

Le découpage avec pas négatif

jours[::-1] inverse une liste. jours[5:1:-1] parcourt à reculons de 5 à 2. Rarement utile, toujours impressionnant.

zip(*...) — la transposition

Python
12
paires = [("a", 1), ("b", 2)]
lettres, nombres = zip(*paires)

L'étoile déballe la liste en arguments séparés. Où chercher : « unpacking argument lists » dans la documentation.

Un défi

À partir de la liste de ventes du travail à rendre, produisez un dictionnaire qui donne, pour chaque département, le produit qui y rapporte le plus — celui dont le chiffre d'affaires cumulé dans ce département est le plus élevé.

C'est difficile, et c'est faisable avec ce que vous savez aujourd'hui plus max(..., key=...). Il vous faudra regrouper sur deux clés à la fois, département et produit, puis chercher le maximum par département. Si vous y arrivez sans compréhension imbriquée, vous avez compris la séance.
