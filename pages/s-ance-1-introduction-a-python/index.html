1. Une même logique, une autre façon de l'écrire

Vous savez déjà programmer. Ce cours ne va pas vous réapprendre les boucles ou les conditions : vous les connaissez. Il va vous apprendre à les exprimer en Python, ce qui n'est pas la même chose.

Regardez ces trois programmes. Ils font exactement la même chose.

En C++

C++
12345678910111213
#include <iostream>
using namespace std;

int main() {
    int nombres[] = {4, 8, 15, 16, 23, 42};
    int taille = 6;
    int total = 0;
    for (int i = 0; i < taille; i++) {
        total += nombres[i];
    }
    cout << "Total : " << total << endl;
    return 0;
}

En PHP

PHP
1234567
<?php
$nombres = [4, 8, 15, 16, 23, 42];
$total = 0;
foreach ($nombres as $nombre) {
    $total += $nombre;
}
echo "Total : " . $total . "\n";

En Python

Python
12
nombres = [4, 8, 15, 16, 23, 42]
print("Total :", sum(nombres))

Les trois affichent Total : 108.

Ce qui a disparu depuis le C++ : les #include, la fonction main, les déclarations de types, la taille du tableau, les accolades, les points-virgules, et la boucle elle-même.

Depuis le PHP, moins de choses ont disparu — et c'est instructif. Si vous venez du PHP, vous avez déjà l'essentiel : pas de compilation, pas de déclaration de type, un tableau qui se crée d'une ligne. Ce qui vous reste à perdre, ce sont les $, les points-virgules, les accolades — et le réflexe d'écrire une boucle là où une fonction existe. En PHP vous auriez pu écrire array_sum($nombres). Python a l'équivalent : sum(nombres).

Les différences à retenir

C / C++ PHP Python
Exécution On compile, puis on exécute On exécute directement le fichier source On exécute directement le fichier source
Types Déclarés à l'avance, vérifiés à la compilation Attachés à la valeur, vérifiés à l'exécution Attachés à la valeur, vérifiés à l'exécution
Blocs Accolades Accolades Indentation
Fin d'instruction Point-virgule obligatoire Point-virgule obligatoire Retour à la ligne
Nom de variable int total = 0; $total = 0; total = 0
Mémoire Gérée à la main en C Gérée automatiquement Gérée automatiquement
Structure minimale Des #include et une fonction main Une balise <?php Une ligne de code suffit

Lisez la colonne qui est la vôtre. Si vous venez du C ou du C++, presque tout change. Si vous venez du PHP, seules trois lignes vous concernent vraiment : les blocs, la fin d'instruction, et le $. Le reste, vous l'avez déjà.

L'indentation fait partie du langage

C'est la différence que personne n'a déjà, ni les uns ni les autres. En Python, décaler une ligne change le programme. Ce n'est pas une question de présentation.

Python
123
for i in range(3):
    print("dans la boucle")
print("après la boucle")

Si vous décalez la dernière ligne de quatre espaces, elle entre dans la boucle et s'exécute trois fois.

Règle du cours : quatre espaces, jamais de tabulation. Le mélange des deux est la première cause d'erreurs chez les débutants en Python. VS Code s'en occupe pour vous si vous le laissez faire.

Typage dynamique ne veut pas dire absence de types

C'est le malentendu le plus fréquent — surtout chez ceux qui viennent du PHP, où le langage se montre beaucoup plus tolérant.

Python
123
x = 10          # x est un entier
x = "bonjour"   # x est maintenant une chaîne : c'est autorisé
resultat = 10 + "bonjour"   # erreur : Python refuse

Python ne vous demande pas de déclarer les types, mais il les vérifie quand même — au moment de l'exécution, pas avant. Conséquence pratique : une erreur de type ne se révèle que lorsque la ligne concernée est effectivement exécutée. Un programme peut donc tourner dix minutes avant de s'arrêter sur une erreur qu'un compilateur C++ aurait signalée tout de suite.

Le point qui surprend ceux qui viennent du PHP : en PHP, 10 . "bonjour" fonctionne et "5" + 3 vaut 8. Python refuse les deux. Il est dynamiquement typé, mais il ne convertit rien tout seul.

Fermez ensuite votre terminal et rouvrez-le, sinon la commande ne sera pas trouvée. Puis vérifiez :

Créer votre premier projet

Terminal
bash
123
uv init cours-python
cd cours-python
uv run main.py

Ces trois lignes créent un projet, y entrent et exécutent le programme de départ. La première exécution prend quelques secondes : uv télécharge Python si nécessaire et prépare l'environnement.

Ce que uv a créé, et à quoi ça sert

Fichier Rôle
pyproject.toml La carte d'identité du projet : son nom, la version de Python, les bibliothèques dont il a besoin
uv.lock Les versions exactes installées, au numéro près
.venv/ L'environnement isolé du projet : son Python et ses bibliothèques, à lui seul
main.py Votre fichier de départ
.python-version La version de Python de ce projet

Pourquoi l'isolation compte. Deux projets sur votre machine peuvent avoir besoin de deux versions différentes de la même bibliothèque. Sans isolation, l'un des deux cesse de fonctionner. Chaque projet a donc son propre .venv, et ils s'ignorent mutuellement.

Si vous venez du PHP, vous connaissez déjà l'idée : pyproject.toml joue le rôle de composer.json, uv.lock celui de composer.lock, et .venv/ celui de vendor/. La ressemblance est presque parfaite.

Ajouter une bibliothèque

Terminal
bash
1
uv add numpy

La bibliothèque est enregistrée dans pyproject.toml, c'est-à-dire dans le projet — et non installée quelque part sur votre machine.

Récupérer le projet de quelqu'un d'autre

Terminal
bash
1
uv sync

uv lit pyproject.toml et uv.lock et reconstitue exactement le même environnement. C'est ce qui vous permettra de récupérer un projet distribué en cours et d'obtenir le même résultat que tout le monde. C'est aussi pour cette raison que vos travaux se rendent sous forme de projet complet, et non de fichier isolé.

Les cinq commandes du cours

Commande Ce qu'elle fait
uv init nom Crée un projet
uv add bibliotheque Ajoute une bibliothèque au projet
uv run fichier.py Exécute un fichier dans l'environnement du projet
uv sync Reconstruit l'environnement à partir du projet
uv python list Montre les versions de Python disponibles

Règle du cours : toujours uv run fichier.py, jamais python fichier.py. La seconde commande utilise un Python quelconque de votre machine plutôt que celui du projet, et c'est la source de la plupart des problèmes inexplicables.

Une fois vos bibliothèques téléchargées, uv fonctionne hors connexion. C'est important ici : téléchargez en salle, sur le réseau de l'établissement, et travaillez chez vous sans réseau. C'est le principal avantage de uv sur un carnet en ligne.

Configurer VS Code

  1. Installez les extensions Python et Jupyter
  2. Ouvrez le dossier du projet, pas seulement le fichier
  3. Sélectionnez l'interpréteur du projet : ouvrez la palette de commandes, tapez Python: Select Interpreter, et choisissez celui qui se trouve dans .venv

L'étape 3 est celle qu'on oublie. Si vous la sautez, VS Code vous dira qu'une bibliothèque est introuvable alors qu'elle est bien installée.

3. Variables et types de base

Une variable est une étiquette, pas une boîte

En C++, une variable est un emplacement mémoire d'une taille fixée. En Python, une variable est un nom collé sur un objet. Réaffecter une variable, c'est décoller l'étiquette et la coller ailleurs.

Cela a une conséquence qui surprend :

Python
1234
a = [1, 2, 3]
b = a          # b est une deuxième étiquette sur le MÊME objet
b.append(4)
print(a)       # [1, 2, 3, 4]

a a changé alors que vous n'y avez pas touché. Nous reviendrons sur ce point en séance 2.

Attention si vous venez du PHP : là-bas, $b = $a sur un tableau en fait une copie, et le tableau d'origine ne bouge pas. Python fait l'inverse. C'est le piège numéro un pour un développeur PHP.

Les types de base

Type Exemple À savoir
int 42 Aucune limite de taille : 2 ** 200 donne le résultat exact
float 3.14 Mêmes imprécisions qu'ailleurs : 0.1 + 0.2 ne vaut pas exactement 0.3
str "bonjour" Pas de type caractère séparé. Une chaîne ne se modifie pas
bool True, False Avec une majuscule, contrairement au C++ et au PHP
NoneType None L'équivalent de NULL

Deux fonctions utiles pour explorer :

Python
12
type(42)        # <class 'int'>
type("42")      # <class 'str'>

Les opérateurs qui surprennent

Python
1234
7 / 2       # 3.5   division réelle, même entre deux entiers
7 // 2      # 3     division entière
7 % 2       # 1     reste
2 ** 10     # 1024  puissance

La première ligne est le piège classique : en C++, 7 / 2 vaut 3. En Python, la division simple donne toujours un nombre décimal. Si vous voulez le comportement auquel vous êtes habitué, utilisez //.

En PHP, 7 / 2 vaut déjà 3.5 — vous êtes en terrain connu. En revanche ** remplace votre pow(), et il existe aussi en PHP depuis longtemps.

Une chaîne ne se modifie pas

Python
123
mot = "bonjour"
mot[0] = "B"          # erreur
mot = "B" + mot[1:]   # on construit une nouvelle chaîne

Là encore une différence avec le PHP, où $mot[0] = "B" fonctionne.

Afficher et saisir

Python
12
nom = input("Votre nom : ")
print("Bonjour", nom)

Attention à ceci, qui tombera dans les exercices :

Python
12345
age = input("Votre âge : ")
print(age + 1)                      # erreur : age est une chaîne

age = int(input("Votre âge : "))    # correct
print(age + 1)

input renvoie toujours une chaîne, quoi que l'utilisateur tape. La conversion est à votre charge. Le PHP, lui, aurait converti tout seul — pas Python.

Les f-strings

C'est la façon moderne d'assembler du texte et des valeurs. Utilisez-les dans ce cours plutôt que la concaténation.

Python
123
nom = "Ana"
note = 17.456
print(f"{nom} a obtenu {note:.1f} sur 20")   # Ana a obtenu 17.5 sur 20

Le :.1f demande un affichage avec une décimale.

C'est l'équivalent de l'interpolation "$nom a obtenu..." du PHP, en plus puissant : vous pouvez mettre une expression et un format entre les accolades. Et cela remplace définitivement la concaténation avec . en PHP ou avec << en C++.

4. Conditions et boucles

La logique vous est connue. Ce qui suit ne concerne que la façon de l'écrire, et ce qui est propre à Python.

Conditions

Python
12345678
note = 14

if note >= 16:
    mention = "très bien"
elif note >= 14:
    mention = "bien"
else:
    mention = "passable"

Trois points d'attention :

  • On écrit elif, pas else if ni elseif
  • Les deux-points en fin de ligne sont obligatoires. C'est l'oubli le plus fréquent des premiers jours
  • Pas de parenthèses autour de la condition

Les opérateurs logiques s'écrivent en toutes lettres : and, or, not — et non &&, ||, !.

Python autorise aussi les comparaisons enchaînées, ce qui n'existe ni en C++ ni en PHP :

Python
12
if 0 <= note <= 20:
    print("note valide")

Méfiez-vous d'un réflexe PHP : le == de Python est strict, comme le === du PHP. Il n'existe pas d'équivalent au == permissif du PHP, et c'est une bonne nouvelle.

Ce que Python considère comme faux

Une liste vide, une chaîne vide, le nombre zéro et None sont considérés comme faux. Tout le reste est vrai.

Python
1234567
notes = []

if notes:                  # façon habituelle en Python
    print("il y a des notes")

if len(notes) > 0:         # fonctionne aussi, mais plus lourd
    print("il y a des notes")

L'idée existe en PHP avec if ($notes), mais la liste de ce qui est « faux » n'est pas la même — en PHP, la chaîne "0" est fausse ; en Python, elle est vraie.

La boucle while

Identique à ce que vous connaissez, à un détail près : ++ et -- n'existent pas en Python.

Python
1234
compteur = 3
while compteur > 0:
    print(compteur)
    compteur -= 1

La boucle for : c'est ici que ça change vraiment

En C et en C++, for compte. En Python, for parcourt.

Python
12
for fruit in ["pomme", "mangue", "avocat"]:
    print(fruit)

Pas d'index, pas de condition d'arrêt, pas d'incrément. Vous dites à Python : pour chaque élément de cette collection, fais ceci.

Si vous venez du PHP, c'est exactement votre foreach. Vous n'avez presque rien à changer — sauf à ne plus jamais écrire la version indexée.

Le réflexe à perdre :

Python
1234567
# Ce que vous écrirez spontanément en venant du C++ ou du PHP
for i in range(len(fruits)):
    print(fruits[i])

# Ce qu'on écrit en Python
for fruit in fruits:
    print(fruit)

La première version fonctionne. Elle n'est pas fausse. Mais elle indique que vous n'écrivez pas encore en Python, et dans ce cours elle sera comptée comme une erreur de style.

Si vous avez réellement besoin de l'indice :

Python
12
for position, fruit in enumerate(fruits):
    print(position, fruit)

C'est l'équivalent du foreach ($fruits as $position => $fruit) du PHP.

Pour parcourir deux collections en parallèle :

Python
12345
noms = ["Ana", "Jean", "Marie"]
notes = [17, 12, 15]

for nom, note in zip(noms, notes):
    print(f"{nom} : {note}")

range, enumerate et zip sont les trois outils à retenir. Ils reviendront pendant tout le cours.

break et continue se comportent comme dans les autres langages.

5. Écrire du Python lisible

PEP 8 est le guide de style officiel de Python. Presque tous les programmeurs Python le suivent, ce qui fait qu'un code conforme est lisible par n'importe qui. Les règles ci-dessous seront appliquées à la correction dès le premier travail.

Règle À faire À éviter
Variables et fonctions note_finale, calculer_moyenne noteFinale, NoteFinale
Classes EtudiantInscrit etudiant_inscrit
Constantes NOTE_MAXIMALE = 20 noteMaximale = 20
Indentation 4 espaces Tabulations, ou 2 espaces
Espaces autour des opérateurs total = a + b total=a+b

Le point le plus visible : Python utilise le snake_case, avec des tirets bas. C'est le premier signe qui trahit un code écrit par quelqu'un venu du PHP, où le camelCase domine. En C++, les conventions varient d'un projet à l'autre — mais notez que la bibliothèque standard du C++ utilise elle aussi le snake_case.

Un exemple

Ce code fonctionne, mais il est écrit comme du PHP :

Python
12345
def calculerMoyenne(listeNotes):
    somme=0
    for i in range(len(listeNotes)):
        somme=somme+listeNotes[i]
    return somme/len(listeNotes)

Voici la version attendue dans ce cours :

Python
123
def calculer_moyenne(notes):
    """Retourne la moyenne d'une liste de notes."""
    return sum(notes) / len(notes)

Cinq changements : le nom de la fonction, le nom du paramètre, la boucle devenue inutile, les espaces autour des opérateurs, et la ligne de documentation.

Les fonctions seront traitées en séance 3. Il n'y a rien à retenir de la syntaxe def pour l'instant : cet exemple ne sert qu'à montrer la différence de style.

Commentaires

Python
1
# Un commentaire explique POURQUOI, pas ce que le code montre déjà

Le texte entre triples guillemets placé au début d'une fonction s'appelle une docstring. Il décrit ce que fait la fonction. Prenez l'habitude d'en écrire.

À retenir de cette séance

  1. Python exprime la même logique avec beaucoup moins de cérémonie, et l'indentation remplace les accolades

  3. La boucle for parcourt des éléments, elle ne compte pas. C'est le premier réflexe à changer
  4. input renvoie toujours une chaîne
  5. On écrit en snake_case, avec quatre espaces d'indentation

L'opérateur ternaire

Python
1
mention = "reçu" if note >= 10 else "ajourné"

Le ?: que vous connaissez, écrit à l'endroit. Pourquoi pas au cours : un if classique est plus lisible pour qui débute, et le ternaire devient vite illisible dès qu'on l'imbrique. Où chercher : documentation Python, « expressions conditionnelles ».

Les annotations de type

Python
12
def calculer_moyenne(notes: list[float]) -> float:
    return sum(notes) / len(notes)

Python permet d'écrire les types sans pour autant les vérifier à l'exécution — ce sont des indications, pour vous, pour votre éditeur et pour des outils comme mypy. Pourquoi pas au cours : on n'a que 16 heures, et ce serait perdre le bénéfice du typage dynamique avant même de l'avoir compris. Mais ça vous parlera si vous venez du C++, et c'est très utilisé en entreprise. Où chercher : typing dans la documentation, puis l'outil mypy.

match / case

L'équivalent du switch, arrivé dans Python 3.10, en beaucoup plus puissant : il sait décomposer des structures, pas seulement comparer des valeurs. Pourquoi pas au cours : récent, et une chaîne de elif suffit à tout ce qu'on fera. Où chercher : « structural pattern matching ».

Le REPL, et python -i

Tapez uv run python sans nom de fichier : vous obtenez un interpréteur interactif où chaque ligne s'exécute immédiatement. C'est l'outil le plus sous-estimé de Python — idéal pour tester une idée en trois secondes au lieu d'écrire un fichier. Pourquoi pas au cours : on l'utilisera en démonstration, sans en faire un chapitre. Essayez tout de suite : uv run python, puis 2 ** 200.

Pourquoi l'indentation ?

Python n'a pas choisi l'indentation par excentricité. Son créateur, Guido van Rossum, venait d'un langage d'enseignement appelé ABC, et le raisonnement était simple : les programmeurs indentent déjà correctement leur code, donc autant que cette indentation soit la structure, plutôt que de la dupliquer avec des accolades qui peuvent la contredire. Où chercher : « The History of Python », le blog de van Rossum.

Regarder ce que Python fait vraiment

Pour ceux qui viennent du C++ et à qui l'absence de compilation manque :

Python
12
import dis
dis.dis(lambda: sum([1, 2, 3]))

Vous verrez le bytecode que Python exécute réellement. Ça ne sert à rien pour le cours, et c'est fascinant. Où chercher : module dis de la bibliothèque standard.
