Exercice 0 — Le projet, et la ligne de la semaine dernière

4 minutes. Socle.

Dans un terminal :

Terminal

uv run main.py

Créez ensuite exercice0.py et collez-y ce que vous aviez écrit la semaine dernière :

Python
123456789
notes_etudiants = [12, 17, 9, 14, 18, 7, 15]

notes_reussite = []
for note in notes_etudiants:
    if note >= 10:
        notes_reussite.append(note)

moyenne = sum(notes_reussite) / len(notes_reussite)
print(f"Moyenne des reçus : {moyenne:.1f}")

Ce qu'on vous demande :

  1. Exécutez-le. Notez l'affichage obtenu — c'est votre référence.
  2. Remplacez les quatre lignes de la boucle par une seule compréhension.
  3. Exécutez à nouveau. L'affichage doit être identique au caractère près.

C'est le seul exercice de la séance dont vous connaissez déjà la réponse attendue. Servez-vous-en : si le résultat change, c'est la compréhension qui est fausse, pas le calcul.

Variante Colab / téléphone. Une cellule pour la version longue, une cellule pour la version courte. Gardez les deux à l'écran, côte à côte.

Exercice 1 — Découper, trier, copier

8 minutes. Socle.

Dans exercice1.py, partez de ces deux listes :

Python
12
jours = ["lundi", "mardi", "mercredi", "jeudi", "vendredi", "samedi", "dimanche"]
temperatures = [31, 29, 33, 35, 30, 28, 32]

Écrivez le code qui affiche, dans cet ordre :

  1. Les cinq premiers jours
  2. Le week-end — les deux derniers, sans écrire le chiffre 5 ni le chiffre 7
  3. Le dernier jour, sans utiliser len
  4. La semaine à l'envers
  5. Un jour sur deux à partir de mardi — le résultat fait trois éléments
  6. Les trois températures les plus élevées, de la plus haute à la plus basse

Puis deux questions, en commentaire à la fin du fichier :

  1. Que vaut jours[:3] + jours[3:] ? Répondez d'abord sans exécuter, puis vérifiez.
  2. Ce code ne fait pas ce qu'on croit. Corrigez-le, et expliquez en une phrase ce qui n'allait pas :
Python
12
temperatures_triees = temperatures.sort()
print(temperatures_triees)

Une contrainte de style : à la question 6, la liste temperatures ne doit pas avoir changé à la fin du programme. Affichez-la en dernière ligne pour le prouver.

Indice pour la question 2. Les index négatifs comptent depuis la fin, et le découpage les accepte aussi.

Variante Colab / téléphone. Identique, en une seule cellule.

Exercice 2 — Compter

10 minutes. Socle — c'est l'exercice le plus important de la séance.

Dans exercice2.py :

Python
12
texte = "riz mais riz haricot riz mais banane"
mots = texte.split()

split() découpe une chaîne sur les espaces et renvoie une liste. C'est tout ce qu'il faut savoir aujourd'hui.

Ce qu'on vous demande :

  1. Construisez un dictionnaire compte qui donne, pour chaque mot, le nombre de fois où il apparaît. Utilisez get(mot, 0).
  2. Affichez-le ligne par ligne, une ligne par mot, de la forme :
Code
1234
riz : 3
mais : 2
haricot : 1
banane : 1
  1. Affichez la liste des mots distincts, triés par ordre alphabétique.
  2. Affichez le mot qui revient le plus souvent.
  3. Construisez, avec une compréhension de dictionnaire, un dictionnaire ne gardant que les mots apparaissant au moins deux fois.

Puis une question, en commentaire à la fin du fichier :

  1. Réécrivez la ligne compte[mot] = compte.get(mot, 0) + 1 sans utiliser get. Votre version fait plus d'une ligne — combien, et pourquoi ?

Indice pour la question 4. max accepte un key=. Sur un dictionnaire, max(compte, key=compte.get) parcourt les clés et compare les valeurs. Prenez trente secondes pour comprendre cette ligne avant de l'écrire : elle réutilise deux choses vues aujourd'hui.

Si la question 5 bloque, faites-la avec une boucle for et un if. C'est juste, c'est noté pareil, et vous y reviendrez.

Variante Colab / téléphone. Identique.

Exercice 3 — Une liste de dictionnaires

8 minutes. Extension — à faire si le socle est terminé.

C'est la forme que prennent toutes les données réelles, et c'est l'exercice qui ressemble le plus au travail à rendre.

Dans exercice3.py :

Python
12345678
releves = [
    {"ville": "Port-au-Prince", "departement": "Ouest",      "temperature": 33, "pluie": 0},
    {"ville": "Jacmel",         "departement": "Sud-Est",    "temperature": 29, "pluie": 12},
    {"ville": "Cap-Haitien",    "departement": "Nord",       "temperature": 31, "pluie": 5},
    {"ville": "Les Cayes",      "departement": "Sud",        "temperature": 30, "pluie": 20},
    {"ville": "Gonaives",       "departement": "Artibonite", "temperature": 35, "pluie": 0},
    {"ville": "Hinche",         "departement": "Centre",     "temperature": 28, "pluie": 8},
]

Affichez, dans cet ordre :

  1. Les noms des villes où il a fait 31 degrés ou plus
  2. La température moyenne, avec une décimale
  3. La ville la plus chaude, et sa température
  4. Les villes triées par pluie décroissante — les noms seulement
  5. Un dictionnaire ville → température, construit en une ligne

Puis :

  1. Ajoutez à chaque relevé une clé sec, valant True s'il n'a pas plu. Affichez ensuite les villes sèches.

Trois contraintes de style :

  • Aucun for i in range(len(releves))
  • Les questions 1, 4 et 5 tiennent chacune sur une ligne
  • La moyenne s'affiche avec une seule décimale

Indice pour la question 6. Une liste de dictionnaires se modifie sur place : for r in releves: puis r["sec"] = .... C'est le seul endroit de l'exercice où une compréhension serait le mauvais outil — vous ne construisez pas une nouvelle liste, vous enrichissez celle-ci.

Variante Colab / téléphone. Identique.

Si vous avez fini en avance

Reprenez exercice3.py. Les six relevés ont chacun un département différent, ce qui rend le regroupement inutile. Ajoutez ces trois lignes :

releves.append({"ville": "Pétion-Ville", "departement": "Ouest",      "temperature": 30, "pluie": 3})

Ce n'est pas une compréhension. C'est deux dictionnaires et une boucle — ou un dictionnaire dont les valeurs sont des listes. Les deux marchent ; comparez-les avec votre voisin.
